## Оставшиеся ограничения (честно)

1. **Нет интеграционного теста с живым PostgreSQL.** Локально Docker недоступен; RLS проверен статически и через мocks. Перед продакшеном нужно применить `rls.sql` к реальной БД под ролью без superuser и прогнать сценарий двух организаций.
2. **OAuth есть только у 4 площадок** (Facebook, Instagram, LinkedIn, X). Остальные 7 подключаются токеном + `metadata`, как и было заявлено — это не полноценный OAuth.
3. **Live-тесты не запускались**: нет внешних кредов и сети до соцсетей. Моковые тесты доказывают логику, но не доступность реальных API.
4. **Ротация устойчива к частичному сбою, но не транзакционна целиком**: каждая запись обновляется отдельно; это сделано сознательно, чтобы можно было продолжить. Требуется мониторинг поля `failed`.
5. **Часовые пояса организаций** пока не реализованы, `scheduledAt` — UTC.
6. WAF, сканирование секретов и внешний аудит логов остаются задачей инфраструктуры.
